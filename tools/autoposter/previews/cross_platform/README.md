## Production safety confirmation

- `CROSS_PLATFORM_GROWTH_ENABLED` defaults to `0`; the disabled pipeline runs no module.
- No changes to publishing schedules, Buffer configuration, YouTube uploader,
  TikTok/Instagram publishing, secrets, production selection weights, voice
  defaults or existing feature flags.
- `src/main.py` and `src/v2_main.py` do not import `src/crossplatform`.
- No login, scraping, paid API or publishing calls; tests patch sockets and
  publishers to prove it.
- Packaging is never applied to production narration or rendered videos;
  every package is `pending_owner_approval`.
- The visual gate only reports (`approved_for_publication: false`).
